ThMap 版本说明 ​

v1.1.4 ​

修复部分问题 ​

  • 修复打包后的TS类型推断问题
  • 修复MarkerOverlay,PopupOverlay的部分问题

优化功能 ​

  • 优化文件转换api，新增layerFieldsOptions参数

v1.1.3 ​

修复部分问题 ​

  • 修复打包后的TS类型推断问题
  • 修复MarkerOverlay,PopupOverlay的部分问题

v1.1.2 ​

修复部分问题 ​

v1.1.1 ​

新增功能 ​

  • 绘图配置新增部分属性(dasharray, activeDasharray)
  • 多边形和折线新增属性(filter, layout)
  • 修复部分问题

v1.1.0 ​

新增功能 ​

  • 绘图配置新增部分属性
  • 绘图工具中优化绘制图片模式，新增图片旋转功能
  • 新增文件转换api

v1.0.0 ​

核心功能 ​

  • 地图基础初始化与配置
  • 瓦片图层管理
  • 多边形（热区）管理
  • 图片叠加层管理
  • 弹窗（Popup）管理
  • 标记点（Marker）管理
  • 地图控制器管理
  • 绘制工具集成

特性亮点 ​

  • 🔧 高效性能：基于 MapBox 实现，性能高效，支持海量数据渲染
  • 📱 简单易用：提供简单的 API 接口，无需复杂配置
  • 🎨 丰富功能：支持瓦片、图片、弹窗、标记和控制器等管理功能
  • 🛠️ 扩展性强：易于扩展和定制，满足不同场景需求

浏览器兼容性 ​

  • Chrome (推荐最新版)
  • Firefox (推荐最新版)
  • Safari (推荐最新版)
  • Edge (推荐最新版)

升级指南 ​

此为初始版本，无需升级指南。
