文件转换 ​

文件转换功能用于将 CAD 等设计文件转换为 GeoJSON 地图数据，方便在地图上进行可视化展示。ThMap 继承自 MapBox 类，天然支持该 API 的调用。

convert ​

文件转换方法，用于将文件转换为 GeoJSON 地图数据。

javascript
/**
 * 转换文件
 * @param {File} file - 文件
 * @param {{text?: string[], polygon?: string[]}} [options] - 图层字段配置
 * @returns {Promise<{data: GeoJSON.FeatureCollection, properties: {center: [number, number], zoom: number}}> | null}
 */
convert(file, options)

参数说明 ​

参数类型描述
fileFile需要转换的文件
optionsobject可选，图层字段配置
options.textstring[]文本图层字段名列表，指定哪些文本字段会被绑定到面属性
options.polygonstring[]面图层字段名列表，指定面图层的优先级排序

返回值 ​

属性类型描述
dataGeoJSON.FeatureCollection转换后的 GeoJSON 要素集合
properties.center[number, number]数据的中心点坐标 [经度, 纬度]
properties.zoomnumber建议的地图缩放级别
properties.rationumber数据的经纬度比例

支持的文件类型 ​

类型扩展名描述
DXF.dxfAutoCAD 图形交换格式

DXF 支持的实体类型 ​

实体类型转换结果描述
POLYLINEPolygon / LineString多段线，闭合则转为面，否则转为线
LWPOLYLINEPolygon / LineString轻量多段线，闭合则转为面，否则转为线
LINELineString直线
TEXTPoint文本标注
MTEXTPoint多行文本标注
ARCLineString圆弧
CIRCLEPolygon / LineString圆形
ELLIPSEPolygon / LineString椭圆，完整椭圆转为面，椭圆弧转为线
INSERT-块引用，递归处理块内实体并应用变换（位移、缩放、旋转）

转换后要素属性 ​

转换后的每个 GeoJSON Feature 都会包含以下 properties：

属性类型描述
idstring实体句柄（handle）
colorstring实体颜色，rgba 格式
layerstringCAD 图层名称
namestring文本内容（仅 TEXT/MTEXT 类型）

示例 ​

javascript
// 基本用法
const fileInput = document.getElementById('file-input')
fileInput.addEventListener('change', async (e) => {
  const file = e.target.files[0]
  if (!file) return

  const result = await map.convert(file)
  if (result) {
    console.log('转换结果:', result.data)
    console.log('中心点:', result.properties.center)
    console.log('缩放级别:', result.properties.zoom)
  }
})

// 使用图层字段配置
const result = await map.convert(file, {
  text: ['roomName', 'roomType'],
  polygon: ['TX', 'GG', 'Wall']
})

DXF 转换示例 ​

javascript
// 完整的 DXF 文件转换和地图展示流程
async function loadDxfFile(file) {
  // 1. 转换文件
  const result = await map.convert(file, {
    polygon: ['TX', 'GG'],
    text: ['roomName']
  })

  if (!result) return

  const { data, properties } = result

  // 2. 添加多边形图层展示面数据
  map.addPolygon('dxf-polygon', {
    source: data,
    defaultColor: ['get', 'color'],
    lineWidth: 1,
    defaultLineColor: '#333'
  })

  // 3. 添加符号图层展示文本标注
  const textFeatures = data.features.filter(f => f.geometry.type === 'Point')
  if (textFeatures.length > 0) {
    map.addSymbol('dxf-text', {
      source: {
        type: 'FeatureCollection',
        features: textFeatures
      },
      layout: {
        'text-field': ['get', 'name'],
        'text-size': 12,
        'text-anchor': 'center'
      },
      paint: {
        'text-color': '#333',
        'text-halo-color': '#fff',
        'text-halo-width': 1
      }
    })
  }

  // 4. 跳转到数据位置
  map.flyTo({
    center: properties.center,
    zoom: properties.zoom
  })
}

// 绑定文件选择事件
document.getElementById('dxf-input').addEventListener('change', (e) => {
  const file = e.target.files[0]
  if (file) {
    loadDxfFile(file)
  }
})

常见问题 ​

  1. 文件格式不支持：目前仅支持 .dxf 格式文件，传入其他格式会打印错误并返回 null。

  2. 转换失败：确保 DXF 文件格式正确，未损坏。如果文件过大，可能需要较长的解析时间。

  3. 坐标偏移：DXF 文件使用的是 CAD 坐标系，转换过程会自动映射到经纬度坐标系。转换结果中的 properties.center 和 properties.zoom 可用于自动定位到数据位置。

  4. 文本未关联到面：可以通过 options.text 和 options.polygon 参数控制文本字段和面图层的关联关系，确保文本点落在对应面的范围内。

  5. 块引用（INSERT）：支持递归处理块引用中的实体，会自动应用位移、缩放和旋转变换。
