符号管理 ​

符号图层用于在地图上显示文本和图标标注，基于 Mapbox GL JS 的 Symbol 图层实现。

addSymbol ​

添加符号图层到地图。

javascript
/**
 * 添加符号图层
 * @param {string} key - 唯一标识
 * @param {thmap.SymbolOptions} options - 配置对象
 * @returns {ThMap} - 返回 this 以支持链式调用
 */
addSymbol(key, options)

参数说明 ​

参数类型描述
keystring符号图层的唯一标识
optionsthmap.SymbolOptions符号图层的配置选项

SymbolOptions 常用配置 ​

选项类型默认值必填描述
sourcethmap.SourceData否数据源，可以是GeoJSON数据集合或数据源ID
beforeIdstring否在某个图层之前的图层key
icon-imagestring否图标图片名称，需先通过 map.loadImage 加载
icon-sizenumber1否图标大小
icon-anchorstring"center"否图标锚点位置
icon-offset[number, number][0, 0]否图标偏移量 [x, y]
icon-rotatenumber0否图标旋转角度
icon-allow-overlapbooleanfalse否图标是否允许重叠
icon-paddingnumber2否图标碰撞检测内边距
icon-pitch-alignmentstring"auto"否图标与视角的对齐方式
icon-rotation-alignmentstring"auto"否图标与地图方向的对齐方式
text-fieldstring否文本字段表达式，如 "{name}" 或 ["get", "name"]
text-fontstring[]否文本字体数组，如 ["Open Sans Regular"]
text-sizenumber16否文本大小
text-anchorstring"center"否文本锚点位置
text-justifystring"center"否文本对齐方式
text-offset[number, number][0, 0]否文本偏移量 [x, y]
text-rotatenumber0否文本旋转角度
text-max-widthnumber10否文本最大宽度(ems)
text-letter-spacingnumber0否文本字间距
text-line-heightnumber1.2否文本行高
text-transformstring"none"否文本转换，可选值：'none'、'uppercase'、'lowercase'
text-allow-overlapbooleanfalse否文本是否允许重叠
text-ignore-placementbooleanfalse否是否忽略文本放置
text-optionalbooleanfalse否文本是否可选（当与图标共存时）
symbol-placementstring"point"否符号放置位置，可选值：'point'、'line'、'line-center'
symbol-spacingnumber250否符号间距（当 placement 为 line 时生效）
visibilitystring"visible"否图层可见性，可选值：'visible'、'none'

SymbolOptions Paint 属性 ​

选项类型默认值必填描述
icon-colorthmap.FeatureColor"#000"否图标颜色
icon-opacitynumber1否图标透明度
icon-halo-colorthmap.FeatureColor"rgba(0,0,0,0)"否图标光晕颜色
icon-halo-widthnumber0否图标光晕宽度
icon-halo-blurnumber0否图标光晕模糊
text-colorthmap.FeatureColor"#000"否文本颜色
text-opacitynumber1否文本透明度
text-halo-colorthmap.FeatureColor"rgba(0,0,0,0)"否文本光晕颜色
text-halo-widthnumber0否文本光晕宽度
text-halo-blurnumber0否文本光晕模糊

SymbolOptions 事件属性 ​

选项类型必填描述
onMouseEnterfunction否鼠标移入事件处理函数
onMouseMovefunction否鼠标移动事件处理函数
onMouseLeavefunction否鼠标移出事件处理函数
onClickfunction否鼠标点击事件处理函数

示例 ​

javascript
// 添加文本标注
map.addSymbol('city-label', {
  source: {
    type: 'FeatureCollection',
    features: [
      {
        type: 'Feature',
        geometry: {
          type: 'Point',
          coordinates: [116.397228, 39.907556]
        },
        properties: {
          name: '北京'
        }
      }
    ]
  },
  layout: {
    'text-field': '{name}',
    'text-font': ['Open Sans Regular'],
    'text-size': 14,
    'text-anchor': 'top',
    'text-offset': [0, 0.5]
  },
  paint: {
    'text-color': '#333',
    'text-halo-color': '#fff',
    'text-halo-width': 1
  }
})

// 添加图标标注
map.addSymbol('marker-icon', {
  source: {
    type: 'FeatureCollection',
    features: [
      {
        type: 'Feature',
        geometry: {
          type: 'Point',
          coordinates: [116.397228, 39.907556]
        },
        properties: {}
      }
    ]
  },
  'icon-image': 'my-icon',
  'icon-size': 0.5,
  'icon-anchor': 'bottom',
  onClick: function(e) {
    console.log('点击了图标:', e.features)
  }
})

setSymbolData ​

设置符号图层数据。

javascript
/**
 * 设置符号图层数据
 * @param {string} key - 唯一标识
 * @param {thmap.SourceData} data - 符号数据
 * @returns {ThMap} - 返回 this 以支持链式调用
 */
setSymbolData(key, data)

参数说明 ​

参数类型描述
keystring符号图层的唯一标识
datathmap.SourceData符号数据，可以是GeoJSON数据或数据源ID

示例 ​

javascript
// 更新符号数据
map.setSymbolData('city-label', {
  type: 'FeatureCollection',
  features: [
    {
      type: 'Feature',
      geometry: {
        type: 'Point',
        coordinates: [116.40, 39.91]
      },
      properties: {
        name: '新位置'
      }
    }
  ]
})

getSymbol ​

获取指定的符号图层实例。

javascript
/**
 * 获取符号图层
 * @param {string} key - 唯一标识
 * @returns {SymbolLayer} - 符号图层实例
 */
getSymbol(key)

参数说明 ​

参数类型描述
keystring符号图层的唯一标识

示例 ​

javascript
const symbol = map.getSymbol('city-label')
// 访问符号图层属性
console.log(symbol.options)

removeSymbol ​

移除符号图层。

javascript
/**
 * 移除符号图层
 * @param {string|string[]} [key] - 唯一标识，不提供则移除所有符号图层
 * @returns {ThMap} - 返回 this 以支持链式调用
 */
removeSymbol(key)

参数说明 ​

参数类型描述
keystring | string[]可选，符号图层的唯一标识，不提供则移除所有符号图层

示例 ​

javascript
// 移除特定符号图层
map.removeSymbol('city-label')

// 移除多个符号图层
map.removeSymbol(['city-label', 'marker-icon'])

// 移除所有符号图层
map.removeSymbol()

setSymbolVisibility ​

设置符号图层的显示状态。

javascript
/**
 * 设置符号图层显示状态
 * @param {layer.VisibilityEnum} visibility - 显示状态('visible' 或 'none')
 * @param {string|string[]} [key] - 唯一标识，不提供则设置所有符号图层
 * @returns {ThMap} - 返回 this 以支持链式调用
 */
setSymbolVisibility(visibility, key)

参数说明 ​

参数类型描述
visibilitylayer.VisibilityEnum显示状态，可选值: 'visible' (显示), 'none' (隐藏)
keystring | string[]可选，符号图层的唯一标识，不提供则设置所有符号图层

示例 ​

javascript
// 显示特定符号图层
map.setSymbolVisibility('visible', 'city-label')

// 隐藏多个符号图层
map.setSymbolVisibility('none', ['city-label', 'marker-icon'])

// 隐藏所有符号图层
map.setSymbolVisibility('none')

map.loadImage('https://example.com/marker.png').then((image) => {

  // 添加图标符号

    source: {
      type: 'FeatureCollection',
      features: [
        {
          type: 'Feature',
          id: 'poi1',
          geometry: {
            type: 'Point',
            coordinates: [116.397228, 39.907556]
          },
          properties: {
            name: '天安门',
            type: '景点'
          }
        },
        {
          type: 'Feature',
          id: 'poi2',
          geometry: {
            type: 'Point',
            coordinates: [116.403, 39.915]
          },
          properties: {
            name: '故宫',
            type: '景点'
          }
        }
      ]
    },
    'icon-image': 'my-marker',
    'icon-size': 0.8,
    'icon-anchor': 'bottom',
    'icon-allow-overlap': true,
    'text-field': '{name}',
    'text-font': ['Open Sans Regular'],
    'text-size': 12,
    'text-anchor': 'top',
    'text-offset': [0, 1],
    'text-allow-overlap': false,

    },
    onMouseEnter: function(e) {
      console.log('鼠标进入:', e.features[0].properties.name)
    }
  })
})

常见问题 ​

  1. 符号不显示：检查数据源是否正确，确保坐标格式符合GeoJSON规范。如果使用了图标，确保已通过 addImage 加载图片。

  2. 文本重叠：可以通过设置 text-allow-overlap: false 和 text-optional: true 来优化文本显示，避免重叠。

  3. 图标不显示：确保 icon-image 的值与通过 addImage 注册的图片名称一致。

  4. 事件不触发：确保符号图层的 icon-allow-overlap 或 text-allow-overlap 没有被设置为 true 导致事件被遮挡。

  5. 性能优化：对于大量符号数据，可以使用 symbol-sort-key 控制渲染顺序，或使用 icon-ignore-placement 和 text-ignore-placement 提升渲染性能。

  6. 响应式配置：SymbolOptions 支持响应式更新，直接修改 layer.options 中的属性即可自动同步到地图。
