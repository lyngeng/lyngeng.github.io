ThMap 介绍 ​

ThMap 是一个高度封装的地图工具，提供了丰富的地图操作功能，包括瓦片管理、图片叠加、图层绘制、弹窗、标记、绘制工具、控制器和测量工具等。

构造函数 ​

javascript
/**
 * 构造函数
 * @constructor
 * @param {string | HTMLElement | object} dom - 容器 DOM 元素或选择器
 * @param {mapboxgl.MapOptions} options - 地图配置选项
 */
constructor(dom, options = {})

参数说明 ​

参数类型描述
domstring | HTMLElement | object地图容器，可以是 DOM 元素对象或 CSS 选择器字符串
optionsmapboxgl.MapOptions地图配置选项，继承自 Mapbox GL JS 的配置选项

options 详细配置 ​

选项类型默认值描述
center[number, number][0, 0]地图中心点坐标 [经度, 纬度]
zoomnumber0地图初始缩放级别
minZoomnumber0地图最小缩放级别
maxZoomnumber22地图最大缩放级别
bearingnumber0地图初始旋转角度（度）
pitchnumber0地图初始倾斜角度（度）
interactivebooleantrue是否允许用户交互
attributionControlbooleantrue是否显示归属控件

示例 ​

javascript
// 使用 CSS 选择器
const map = new ThMap('#map-container', {
  center: [116.397228, 39.907556],
  zoom: 12
})

// 使用 DOM 元素
const container = document.getElementById('map-container')
const map = new ThMap(container, {
  center: [116.397228, 39.907556],
  zoom: 12,
  minZoom: 5,
  maxZoom: 18
})

功能模块 ​

ThMap 提供了以下核心功能模块：

瓦片管理 ​

管理地图瓦片图层，支持添加、获取、移除和控制可见性。

方法说明
addTile添加瓦片图层
getTile获取瓦片图层实例
removeTile移除瓦片图层
setTileVisibility设置瓦片图层可见性

图片叠加 ​

管理地图图片图层，支持添加、获取、移除和控制可见性。

方法说明
addImg添加图片图层
getImg获取图片图层实例
removeImg移除图片图层
setImgVisibility设置图片图层可见性

多边形图层 ​

管理地图多边形（热区）图层，支持鼠标交互事件和样式配置。

方法说明
addPolygon添加多边形图层
setPolygonData设置多边形数据
getPolygon获取多边形图层实例
removePolygon移除多边形图层
setPolygonVisibility设置多边形图层可见性

折线图层 ​

管理地图折线图层，支持鼠标交互事件和样式配置。

方法说明
addPolyline添加折线图层
setPolylineData设置折线数据
getPolyline获取折线图层实例
removePolyline移除折线图层
setPolylineVisibility设置折线图层可见性

符号图层 ​

管理地图符号图层，用于显示文本和图标标注。

方法说明
addSymbol添加符号图层
setSymbolData设置符号数据
getSymbol获取符号图层实例
removeSymbol移除符号图层
setSymbolVisibility设置符号图层可见性

弹窗管理 ​

管理地图弹窗覆盖物。

方法说明
addPopup添加弹窗
getPopup获取弹窗实例
removePopup移除弹窗
setPopupProp设置弹窗属性
setPopupVisibility设置弹窗可见性

标记管理 ​

管理地图标记覆盖物。

方法说明
addMarker添加标记
getMarker获取标记实例
removeMarker移除标记
setMarkerProp设置标记属性
setMarkerVisibility设置标记可见性

绘制工具 ​

提供地图绘制功能，支持绘制点、线、面等几何图形。

方法说明
addDraw添加绘制工具
getDraw获取绘制工具实例
removeDraw移除绘制工具

控制器管理 ​

管理地图控制器，如比例尺、导航、鹰眼图等。

方法说明
addControl添加控制器
getControl获取控制器实例
removeControl移除控制器

完整示例 ​

javascript
import { ThMap } from '@/classes/ThMap/ThMap'

// 创建地图实例
const map = new ThMap('#map-container', {
  center: [116.397228, 39.907556],
  zoom: 12
})

// 添加瓦片图层
map.addTile('base', {
  tiles: ['https://your-tile-server.com/{z}/{x}/{y}.png']
})

// 添加多边形热区
map.addPolygon('region', {
  source: geojsonData,
  defaultColor: 'rgba(105,164,236,0.3)',
  hoverColor: 'rgba(105,164,236,0.5)',
  onClick: (e) => {
    console.log('点击了热区:', e.features)
  }
})

// 添加标记
map.addMarker('point', {
  coordinate: [116.397228, 39.907556]
})

// 添加控制器
map
  .addControl('navigation', { position: 'top-right' })
  .addControl('scale', { position: 'bottom-left' })
  .addControl('miniMap', { position: 'bottom-right' })

// 添加测量工具
const distanceMeasurer = map.addMeasurer('distance', {
  onMeasure: (result) => {
    console.log('测量距离:', result.distance)
  }
})

// 销毁地图
map.remove()
