绘制工具 ​

绘制工具允许用户在地图上绘制点、线、面等几何图形，并支持编辑和管理这些图形。

addDraw ​

添加绘制工具到地图。

javascript
/**
 * 添加绘制工具
 * @param {thmap.DrawOptions} [options] - 配置对象
 * @returns {ThMap} - 返回 this 以支持链式调用
 */
addDraw(options)

参数说明 ​

参数类型描述
optionsthmap.DrawOptions可选，绘制工具的配置选项

DrawOptions 详细配置 ​

选项类型默认值必填描述
displayControlsDefaultbooleanfalse否是否显示默认控件
autoCreateCenterTextbooleanfalse否是否自动创建中心文字
midPointbooleantrue否是否开启绘制顶点
fillColorthmap.FeatureColorrgba(59,178,208,0.3)否填充颜色，填写颜色值（如："#fff"）或feature.properties中的属性名称
fillActiveColorthmap.FeatureColorrgba(59,178,208,0.5)否激活状态填充颜色
fillLineColorthmap.FeatureColorrgba(59,178,208,1)否面边框颜色
fillLineActiveColorthmap.FeatureColorrgba(251,176,59,1)否激活面边框颜色
fillLineWidthnumber3否面边框宽度
lineColorthmap.FeatureColor#3BB2D0否线条颜色
lineActiveColorthmap.FeatureColor#3BB2D0否激活状态线条颜色
lineWidthnumber3否线条宽度
pointColorthmap.FeatureColor#3BB2D0否点颜色
pointActiveColorthmap.FeatureColor#3BB2D0否激活状态点颜色
pointOuterColorthmap.FeatureColor#ffffff否点外框颜色
pointOuterActiveColorthmap.FeatureColor#ffffff否激活状态点外框颜色
pointRadiusnumber5否点半径
vertexColorthmap.FeatureColor#fbb03b否顶点颜色
vertexActiveColorthmap.FeatureColor#fbb03b否激活状态顶点颜色
vertexOuterColorthmap.FeatureColor#ffffff否顶点外框颜色
vertexOuterActiveColorthmap.FeatureColor#ffffff否激活状态顶点外框颜色
vertexRadiusnumber3否顶点半径
midpointColorthmap.FeatureColor#fbb03b否中点颜色
midpointRadiusnumber3否中点半径
imageLineColorthmap.FeatureColortransparent否图片边框颜色
imageLineActiveColorthmap.FeatureColor#fbb03b否激活图片边框颜色
imageLineWidthnumber3否边框宽度
dasharray[number, number]-否点线宽度
activeDasharray[number, number]-否激活状态点线宽度

支持的绘制模式 ​

模式常量描述
simple_selectSIMPLE_SELECT简单选择模式，可以选择、移动和编辑图形
direct_selectDIRECT_SELECT直接选择模式，可以选择和编辑图形的顶点
frame_selectFRAME_SELECT框选模式，通过拖动框选多个图形
draw_pointDRAW_POINT点绘制模式
draw_line_stringDRAW_LINE_STRING折线绘制模式
draw_polygonDRAW_POLYGON多边形绘制模式
draw_rectangleDRAW_RECTANGLE矩形绘制模式
draw_circleDRAW_CIRCLE圆形绘制模式
draw_modelDRAW_MODEL模型绘制模式
draw_imageDRAW_IMAGE图片绘制模式
draw_splitDRAW_SPLIT分割模式
draw_split_percentageDRAW_SPLIT_PERCENTAGE分割百分比模式
draw_mergeDRAW_MERGE合并模式

完整的绘制模式类型定义请参考 DrawMode 和 DrawConstants.DrawModes

示例 ​

javascript
// 添加绘制工具
map.addDraw({
  fillColor: 'rgba(255, 0, 0, 0.2)',
  lineColor: '#ff0000',
  lineWidth: 2
})

// 添加绘制工具并配置样式选项
map.addDraw({
  fillColor: 'rgba(0, 0, 255, 0.2)',
  lineColor: '#0000ff',
  lineWidth: 2,
  pointRadius: 6,
  vertexRadius: 4
})

绘制工具方法 ​

changeMode ​

切换绘制模式。

javascript
/**
 * 切换绘制模式
 * @param {mapdraw.DrawMode} mode - 绘制模式
 * @param {object} [options] - 模式配置
 * @returns {MapDraw} - 绘制工具实例
 */
changeMode(mode, options)

参数说明 ​

参数类型描述
modemapdraw.DrawMode绘制模式
optionsobject可选，模式配置

示例 ​

javascript
// 切换到多边形绘制模式
map.getDraw().changeMode('draw_polygon')

// 切换到选择模式并选择特定图形
map.getDraw().changeMode('simple_select', { featureIds: ['feature1', 'feature2'] })

// 切换到直接选择模式并编辑特定图形
map.getDraw().changeMode('direct_select', { featureId: 'feature1' })

// 切换到折线绘制模式并从指定点开始
map.getDraw().changeMode('draw_line_string', { 
  featureId: 'feature1', 
  from: [116.397228, 39.907556] 
})

// 百分比模式切换
map.getDraw().changeMode('draw_split', {
  // 分割方向：'vertical'(垂直) 或 'horizontal'(水平)，默认 'vertical'
  direction: 'vertical',
  // 分割百分比：0-100 之间的数值，默认 50
  percentage: 30,
  // 分割步长：拖动时的增量，默认 0.1
  step: 0.5,
  // 分割小数位数：百分比显示的小数位数，默认 1
  decimals: 2
})

add ​

添加绘制图形。

javascript
/**
 * 添加绘制图形
 * @param {GeoJSON.Feature | GeoJSON.FeatureCollection | GeoJSON.Geometry} geojson - 绘制图形数据
 * @returns {MapDraw} - 绘制工具实例
 */
add(geojson)

参数说明 ​

参数类型描述
geojsonGeoJSON.Feature | GeoJSON.FeatureCollection | GeoJSON.Geometry绘制图形数据

示例 ​

javascript
// 添加一个点
map.getDraw().add({
  type: 'Feature',
  geometry: {
    type: 'Point',
    coordinates: [116.397228, 39.907556]
  },
  properties: {
    name: '中心点'
  }
})

// 添加一条线
map.getDraw().add({
  type: 'Feature',
  geometry: {
    type: 'LineString',
    coordinates: [
      [116.38, 39.90],
      [116.40, 39.90]
    ]
  },
  properties: {
    name: '道路'
  }
})

// 添加一个多边形
map.getDraw().add({
  type: 'Feature',
  geometry: {
    type: 'Polygon',
    coordinates: [[
      [116.38, 39.90],
      [116.40, 39.90],
      [116.40, 39.92],
      [116.38, 39.92],
      [116.38, 39.90]
    ]]
  },
  properties: {
    name: '区域'
  }
})

绘制工具事件 ​

onCreate ​

监听绘制创建事件。

javascript
/**
 * 监听绘制创建事件
 * @param {function} callback - 回调函数，参数为 DrawCreateEvent
 * @returns {MapDraw} - 绘制工具实例
 */
onCreate(callback)

事件参数 ​

属性名类型常量描述
type"draw.create"CREATE事件类型
targetMap-地图实例
featuresFeature[]-创建的要素数组

完整的事件类型常量请参考 DrawConstants.events

示例 ​

javascript
// 监听创建事件
map.getDraw().onCreate(function(e) {
  console.log('创建了图形:', e.features)
  console.log('创建图形数量:', e.features.length)
  
  // 为新创建的图形设置属性
  e.features.forEach(function(feature) {
    map.getDraw().setFeatureProperty(feature.id, 'createdAt', new Date().toISOString())
  })
})

绘制工具操作示例 ​

基本使用示例 ​

javascript
// 添加绘制工具并设置事件监听
map.addDraw({
  fillColor: 'rgba(0, 0, 255, 0.2)',
  lineColor: '#0000ff',
  lineWidth: 2
})

const draw = map.getDraw()

// 监听创建事件
draw.onCreate(function(e) {
  console.log('创建了图形:', e.features)
  // 为新创建的图形设置属性
  e.features.forEach(function(feature) {
    draw.setFeatureProperty(feature.id, 'createdAt', new Date().toISOString())
  })
})

// 监听更新事件
draw.onUpdate(function(e) {
  console.log('更新了图形:', e.features)
})

// 监听删除事件
draw.onDelete(function(e) {
  console.log('删除了图形:', e.features)
})

// 监听选择变化事件
draw.onSelectionChange(function(e) {
  console.log('选择了图形:', e.features)
})

// 监听模式变化事件
draw.onModeChange(function(e) {
  console.log('切换到模式:', e.mode)
})

动态切换模式示例 ​

javascript
// 添加绘制工具
map.addDraw({
  fillColor: 'rgba(255, 0, 0, 0.2)',
  lineColor: '#ff0000',
  lineWidth: 2
})

const draw = map.getDraw()

// 切换到多边形绘制模式
setTimeout(function() {
  draw.changeMode('draw_polygon')
  console.log('开始绘制多边形')
}, 1000)

// 3秒后切换到选择模式
setTimeout(function() {
  draw.changeMode('simple_select')
  console.log('切换到选择模式')
}, 4000)

// 5秒后删除所有图形
setTimeout(function() {
  draw.clear()
  console.log('清空所有图形')
}, 8000)

编辑现有图形示例 ​

javascript
// 添加绘制工具
map.addDraw()

const draw = map.getDraw()

// 添加一个图形
const feature = {
  type: 'Feature',
  id: 'my-feature',
  geometry: {
    type: 'Polygon',
    coordinates: [[
      [116.38, 39.90],
      [116.40, 39.90],
      [116.40, 39.92],
      [116.38, 39.92],
      [116.38, 39.90]
    ]]
  },
  properties: {
    name: '可编辑区域'
  }
}

draw.add(feature)

// 切换到直接选择模式编辑该图形
setTimeout(function() {
  draw.changeMode('direct_select', { featureId: 'my-feature' })
  console.log('开始编辑图形')
}, 1000)

// 监听更新事件
draw.onUpdate(function(e) {
  console.log('图形已更新:', e.features[0].geometry.coordinates)
})

常见问题 ​

  1. 绘制工具不显示：检查是否已添加绘制工具，确保地图容器有足够的尺寸。

  2. 绘制图形不保存：确保在绘制完成后正确处理了创建事件，并保存了绘制数据。

  3. 性能优化：对于复杂的绘制场景，可以考虑限制绘制图形的数量，或使用数据简化来提高性能。

  4. 内存泄漏：确保在不需要绘制工具时调用destroy()方法释放资源。

  5. 事件监听重复：避免多次添加相同的事件监听器，可以使用off方法移除之前的监听器。

  6. 图形ID冲突：确保添加的图形具有唯一的ID，避免使用系统保留的ID（如VERTICAL_GUIDE、HORIZONTAL_GUIDE、ROTATE_VERTEX）。
